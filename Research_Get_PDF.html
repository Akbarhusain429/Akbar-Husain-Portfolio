Case Study // File 06

Autonomous Multi-Agent Deep Research Engine

An industrial-grade autonomous research workflow built in n8n that eliminates manual literature reviews. Taking any raw research query, it orchestrates 4 LLM agents, performs 5 concurrent web search streams, aggregates 25 real-time verified citations, and compiles an executive PDF delivered straight to the recipient's inbox.

01. Strategic Ingestion & Planning Deconstructs user queries into 5 mutually exclusive, high-impact subtopics using dynamic agent reasoning.
02. Parallel Web Research & Synthesis Executes 5 concurrent Tavly search pipelines, attributing 25 distinct source citations directly into written chapters.
03. Google Sheets State Sync & TOC Maintains execution state across parallel forks and dynamically synthesizes the Table of Contents & reference index.
04. Executive PDF Generation & Delivery Renders clean HTML/CSS to PDF via APITemplate.io and dispatches the final attachment via Gmail API.
